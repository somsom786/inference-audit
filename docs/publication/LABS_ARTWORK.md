# Labs artwork and evidence provenance

The silicon plate, results poster layout and figures are original programmatic artwork produced for Inference Audit Labs, distributed under the repository MIT license. The die plate is a schematic of a package and does not claim to reproduce the physical layout of the RTX 4070. The checked-in [builder](../../scripts/publication/build_labs.py) projects the archived public measurements into the [data used by the interactive comparisons](../../public/evidence/labs-results.json), then renders the [editable SVG poster](../../public/assets/labs-results-poster.svg) and [1200 × 630 Open Graph PNG](../../public/assets/labs-social.png). A 2× PNG can be rendered locally with the same builder. All poster performance figures use the experiment definitions in the [claims ledger](CLAIMS_LEDGER.md).
