From endpoint to evidence

Follow an audit from the first connection to a report you can check offline.

Check the endpoint

Point the CLI at an endpoint you control or have permission to test. Inspect its discovery routes before approving traffic.

inference-audit inspect --url http://127.0.0.1:8080

Send bounded test traffic

Set the model, workload mix, arrival rate and deadlines. The audit records completed, late, rejected and failed work.

inference-audit benchmark --config configs/local.yaml --run first-local --approve-load

Check the saved evidence

Validate local digests and the structure of the recorded transactions. The report retains the original task-check outcomes.

inference-audit verify --run first-local

Rebuild the report offline

Review latency, throughput, useful capacity and the limits of each comparison. Share the standalone HTML report.

inference-audit report --run first-local
