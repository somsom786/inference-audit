The public label and run ID are aliases, precise start/end timestamps were removed, and the original optional cost scenario was left out. Metrics and scoped task-check outcomes were retained. The derived public files carry no raw messages or answers. Local integrity seals cover the original native evidence and do not authenticate the operator or re-grade responses that were withheld.
